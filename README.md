# 🩸 Bharosa Lab - Digital Healthcare Ecosystem

Bharosa Lab is a comprehensive, 3-way SaaS platform engineered to revolutionize pathology lab testing through seamless home-sample collection. It eliminates wait times and traffic hassles by connecting patients directly with trusted diagnostic centers and localized riders.

### 🚀 The Ecosystem
1. **📱 Patient App (React Native / Expo):** For booking home test collections, tracking riders live on a map, and securely downloading digital PDF reports.
2. **🏍️ Rider App (React Native / Expo):** Dedicated app for phlebotomists/riders to manage trip routes, patient locations, and sample pickups in real-time.
3. **💻 Lab Partner & Super Admin Portal (Next.js & Supabase):** A centralized, high-security dashboard for lab owners and platform admins. Features include dynamic test catalogs, live booking tracking, automated commission thresholds, and real-time financial ledger analytics.

### 🛠️ Tech Stack
* **Frontend/Web:** Next.js, TailwindCSS, TypeScript
* **Mobile Apps:** React Native, Expo
* **Backend & Database:** Supabase (PostgreSQL, Storage, Edge Functions)
* **Architecture:** Real-time state management, secure auth, and automated billing workflows.
