# Project Brief

## Project Name
Bharosa Lab - Digital Healthcare Ecosystem (Admin/Lab Portal)

## Purpose and Scope
Bharosa Lab is a comprehensive SaaS platform designed to modernize pathology lab testing by offering seamless home-sample collection. The system bridges the gap between patients, localized riders (phlebotomists), and diagnostic centers, eliminating wait times and streamlining healthcare workflows. 

The scope of this specific project directory (`lab-ghar`) covers:
1. **Lab Partner Portal:** A highly secure dashboard for individual laboratory owners to manage their test catalogs, monitor live bookings, and process digital reports.
2. **Super Admin Portal:** A centralized administrative system allowing platform owners to monitor the entire ecosystem, including lab onboarding, rider management, financial ledgers, and dynamic ads/promotions.

## Key Objectives
- Provide a robust interface for lab partners to manage their daily operations.
- Enable real-time updates and notifications for new test bookings.
- Provide a holistic operational view for super admins to manage labs, riders, orders, and platform billing.
- Ensure strict security and data segregation (Role-based access for Lab Admins vs Super Admins).
